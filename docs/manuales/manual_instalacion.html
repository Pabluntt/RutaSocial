Manual de Instalación

Sistema: RutaSocial

Este manual describe la instalación local con Docker Compose y la ejecución separada de Backend y FrontendWeb.

Requisitos

  • Git
  • Docker Desktop con Docker Compose
  • Node.js compatible con el proyecto para desarrollo frontend
  • Go 1.24 para desarrollo backend

Variables de Entorno

Copiar los archivos de ejemplo y ajustar valores locales:

Backend/.env.example -> Backend/.env
FrontendWeb/.env.example -> FrontendWeb/.env
VariableUso
MONGODB_URIConexión MongoDB usada por el backend.
JWT_SECRETClave para firmar tokens JWT. Debe ser segura en producción.
APP_ENVEntorno de ejecución. En producción oculta Swagger.
VITE_URL_BACKENDURL del backend consumida por FrontendWeb.
VITE_BASE_URLBase path usado por navegación frontend.

Instalación con Docker Compose

  1. Abrir terminal en la raíz del repositorio.
  2. Construir imágenes.
  3. Levantar servicios.
docker compose build
docker compose up -d
docker compose ps

Puertos Locales

ServicioPuertoDescripción
FrontendWeb3000Aplicación web.
Backend8080API REST.
MongoDB27017Base de datos local si se usa el contenedor.

Desarrollo sin Docker

Backend

cd Backend
go mod download
go test ./...
go run ./cmd

FrontendWeb

cd FrontendWeb
npm ci
npm run typecheck
npm run test
npm run dev

Verificación

  • Frontend disponible en http://localhost:3000.
  • Backend disponible en http://localhost:8080.
  • MongoDB debe figurar como healthy en Docker Compose.
  • Ejecutar pruebas antes de desplegar cambios.

Producción

  • Usar secretos reales en variables de entorno, no en código.
  • Configurar dominios finales para CORS y CSP.
  • Usar APP_ENV=production para ocultar Swagger.
  • Construir imágenes nuevas después de cada cambio.
No eliminar volúmenes Docker si se desea conservar la base de datos local.
