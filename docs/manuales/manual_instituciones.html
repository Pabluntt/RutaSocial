Manual de Instituciones

Sistema: RutaSocial

Importante: Institución no es un rol de inicio de sesión. Es un registro administrado dentro del sistema que funciona como etiqueta organizativa.

Qué es una Institución

Una institución representa una organización relacionada con los usuarios u operación territorial (por ejemplo: municipalidad, fundación, centro comunitario, iglesia, etc.). Sirve como dato administrativo para ordenar la información y facilitar la coordinación entre equipos.

La institución se asocia a los usuarios como un campo en su perfil. No define permisos de acceso ni restringe qué datos puede ver cada usuario.

Gestión de Instituciones

  1. Ingresar con una cuenta administradora.
  2. Abrir la sección de gestión de instituciones (disponible en el panel de administración).
  3. Crear una institución con datos claros y verificables (nombre, descripción, datos de contacto si aplica).
  4. Editar la institución si cambia su información.
  5. Eliminar solo instituciones que ya no estén asociadas a usuarios activos u operación vigente.

Buenas Prácticas

  • Usar nombres consistentes y completos para evitar duplicados (ej: "Municipalidad de Santiago" en lugar de "Muni Sgo" o "Muni Stgo").
  • Evitar crear instituciones con variaciones menores del mismo nombre; verificar si ya existe antes de crear.
  • Revisar las asociaciones con usuarios antes de eliminar una institución.
  • Centralizar la creación en administradores para mantener calidad y consistencia de los datos.
  • Documentar internamente a qué organización real corresponde cada institución si hay muchas similares.

Política Actual

  • La institución funciona como nombre o etiqueta asociada al usuario; no define permisos de acceso a datos.
  • No se usa para control de acceso hasta que exista una regla operativa formal que lo requiera.
  • Los voluntarios pueden consultar instituciones para contexto operativo, pero no administrarlas.
La política de instituciones puede evolucionar en el futuro si se requiere segmentar permisos por organización. Por ahora, es un dato administrativo sin efectos en la seguridad del sistema.
