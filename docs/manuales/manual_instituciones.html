Manual de Instituciones

Sistema: RutaSocial

Importante: institución no es un rol de inicio de sesión. Es un registro administrado dentro del sistema.

Qué es una Institución

Una institución representa una organización relacionada con usuarios u operación territorial. Sirve como dato administrativo para ordenar la información y facilitar coordinación.

Permisos Relacionados

RolPuede hacerNo puede hacer
AdministradorVer, crear, editar y eliminar instituciones.No aplica.
VoluntarioVer instituciones disponibles.Crear, editar o eliminar instituciones.

Gestión de Instituciones

  1. Ingresar con una cuenta administradora.
  2. Abrir la sección de gestión de usuarios o institución, según la pantalla disponible.
  3. Crear una institución con datos claros y verificables.
  4. Editar la institución si cambia su información.
  5. Eliminar solo instituciones que ya no estén asociadas a operación vigente.

Buenas Prácticas

  • Usar nombres consistentes y completos.
  • Evitar duplicar instituciones con variaciones menores del nombre.
  • Revisar asociaciones antes de eliminar.
  • Centralizar la creación en administradores para mantener calidad de datos.
Los voluntarios pueden consultar instituciones para contexto operativo, pero no administrarlas.
