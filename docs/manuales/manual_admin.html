Manual de Administrador

Sistema: RutaSocial

Perfil: usuario con rol administrador.

Alcance del Rol

El administrador mantiene la operación general del sistema. Puede ver la información operativa, crear usuarios, gestionar instituciones y administrar registros críticos.

Permisos del Administrador

MóduloPermisos
UsuariosVer usuarios, crear voluntarios, crear administradores, editar usuarios y eliminar usuarios.
InstitucionesVer, crear, editar y eliminar instituciones.
RutasCrear rutas, unirse a rutas, ver rutas, editar rutas, eliminar rutas y finalizar cualquier ruta.
Informes de rutaVer datos de rutas y descargar informes completos.
MapaVer puntos de ayuda, riesgos, mapas de calor, rutas y alojamientos.
AlojamientosCrear alojamientos desde el mapa. Este botón solo debe estar disponible para administradores.
Personas ayudadasVer, crear, editar y eliminar perfiles; gestionar antecedentes e información médica.
Puntos de ayudaCrear, editar, eliminar y vincular puntos de ayuda con personas beneficiadas.
AvisosCrear avisos para voluntarios y visualizar avisos fijados.
CalendarioVer y gestionar eventos de calendario asociados a rutas.

Funciones Principales

Gestionar Usuarios

Desde el panel de usuarios se pueden revisar cuentas, crear nuevos voluntarios o administradores, editar información y eliminar cuentas cuando corresponda.

Gestionar Instituciones

Permite mantener el listado de instituciones asociadas a usuarios y operación. Solo administradores pueden crear, modificar o eliminar instituciones.

Gestionar Rutas

La sección de gestión de rutas permite revisar datos de rutas y descargar informes. También muestra acciones administrativas cuando corresponda.

Mapa y Alojamientos

El administrador puede crear alojamientos desde el mapa. Para voluntarios, el botón de creación no debe mostrarse.

Personas Ayudadas

El administrador puede mantener perfiles de personas beneficiadas, antecedentes, información médica y vínculos con puntos de ayuda.

Buenas Prácticas

  • Crear administradores solo cuando sea estrictamente necesario.
  • Revisar que las instituciones estén correctas antes de asociarlas a usuarios.
  • Descargar informes de ruta para respaldo operativo cuando se finalice una actividad.
  • Cerrar sesión al terminar, especialmente en equipos compartidos.
El registro público siempre crea voluntarios. La creación de administradores se realiza desde funciones protegidas para administradores.
